# 2026 春水堂班級點餐

靜態點餐網站，提供全飲品選單、即時計價與目前點餐狀況頁面。訂單會寫入 Google Sheet `2026手搖飲點餐記錄`。

## Google Apps Script

1. 建立同名 Google Sheet，於「擴充功能 → Apps Script」貼上 [`Code.gs`](Code.gs)。
2. 部署為 Web app（以你的身分執行、任何人可存取），將網址填入 [`config.js`](config.js)。
